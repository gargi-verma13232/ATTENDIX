# Attendix

A modern attendance management application built with React, Vite, and Tailwind CSS. 

## Live Demo
[View Live Project](https://agent-6a2c5c90d242d793fb5315b7--attendixz.netlify.app)

## Features
- **Dashboard & Analytics:** Visualize attendance data using Recharts.
- **Modern UI:** Built with Tailwind CSS and Lucide React icons for a responsive, clean interface.
- **Fast Performance:** Lightning-fast build and development server powered by Vite.

## Tech Stack
- React 19
- Vite
- Tailwind CSS
- React Router DOM
- Recharts
- Lucide React

## Getting Started

To run this project locally:

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. Open `http://localhost:5173` in your browser.

## Deployment
This project is configured for continuous deployment on Netlify. Any changes pushed to the connected repository are automatically built and published.
